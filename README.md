# Painel privado do PET Conecta

Site separado, com login por e-mail, para ver as estatísticas do PET Conecta e cuidar das mensagens de Fale com o PET.
Só entram e-mails da tabela `pet_painel_acesso` (Supabase); tudo é conferido no banco pelas funções `pet_painel_*`.
Esta branch não tem relação com o site público (branch `main`).
